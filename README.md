# Kajazoma — site professionnel final

Les 10 photos fournies pour cette version sont intégrées directement dans `images/` au format WebP.
Elles ont reçu une optimisation légère de contraste/couleur et un traitement de netteté doux, sans
agrandissement artificiel, afin de préserver leur rendu original.

Le site comprend la page d'accueil, le menu, la galerie locale, la page de réservation via WhatsApp,
les liens sociaux, le SEO, le manifeste, robots.txt et sitemap.xml.

Les prix non vérifiés restent indiqués « Sur demande ». La réservation est une demande via WhatsApp
et non une confirmation automatique.

L'adresse affichée suit les informations publiques récentes utilisées pour le site
(Deux-Plateaux / Cocody, Abidjan) et doit être confirmée avec le restaurant avant publication définitive.
